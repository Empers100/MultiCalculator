# Multi Calculator

A powerful, all-in-one calculator for Android, featuring a standard calculatorand date difference calculator. Supports English, Russian, and Chinese languages, dark/light themes, memory functions, and share results.

## ✨ Features

- **Standard Calculator**: basic arithmetic, percentages, square root, reciprocal, x², x³.
- **Date Calculator**: calculate exact difference between two dates with correct plural forms.
- **Memory**: MC, MR, M+, M- (shared between standard and scientific modes).
- **Themes**: Light and Dark.
- **Multilingual**: English, Русский, 中文.
- **Share**: share your calculation results via any app.
